# EPick - AI Voice Assistant

EPick is a Python-based voice assistant that enables hands-free interaction with the system using speech recognition and text-to-speech capabilities. It automates everyday tasks like web browsing, media control, system operations, email handling, and more.

---

## 🚀 Overview

EPick is designed to simulate a personal voice assistant that responds to user voice commands and performs system-level and web-based operations efficiently.

---

## ✨ Features

- Voice recognition and speech response
- Open websites (Google, YouTube, Facebook)
- Wikipedia search with spoken summaries
- Play local music files
- Get current system time
- Send emails with optional attachments
- System automation (open/close apps, switch windows, clipboard operations)
- Media controls (play, pause, volume control, navigation)
- Read text from screen using clipboard
- Train ticket booking automation via web browser

---

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- Wikipedia API
- PyAutoGUI
- SMTP (Email automation)
- Webbrowser
- Requests
- Selenium
- Win32 Clipboard
